## Runner actions

- **`swipe`**: Touch swipe gesture at pixel coordinates. Used for scrolling the Settings screen to reach "App Permissions" row (below fold on S21).
- **`wait_for_package`**: Waits for a specific Android package in the foreground. Detects navigation to system settings.

## Navigation strategy

Settings-based navigation (Chat top bar → Settings → scroll → "App Permissions") avoids the drawer scroll issue: UiAutomator cannot find Compose drawer items below the visible viewport.

## Row-specific state assertions

Changed the `PermissionRow` trailing icon `contentDescription` from generic `"Granted"`/`"Not granted"` to row-qualified `"<label> granted"`/`"<label> not granted"` (e.g. `"Location granted"`, `"Microphone not granted"`). Scenario `expected_visible` assertions now check the specific row's qualified description, preventing false-pass when a different row has the same grant state.
