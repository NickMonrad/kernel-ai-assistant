# Evidence Manifest Format

A lightweight evidence manifest that can be pasted into PR bodies and optionally saved under
`docs/test-triage/evidence/` when durable tracking is useful.

The manifest is free-text markdown — no hard CI validation in this iteration.
It helps reviewers quickly understand what evidence was collected and what was waived.

## When to Use

- **Every non-trivial PR should include an evidence manifest.** Paste the relevant fields into
  the PR description.
- **Pure docs/template/copy-only PRs** may use a short validation note instead of the full
  manifest (see the PR template for the docs-only checklist).
- **Complex or long-running PRs** may save a copy to
  `docs/test-triage/evidence/pr-<N>-manifest.md` for durable tracking.


## Template

```markdown
## Evidence Manifest

### PR Metadata
- **PR number:** #
- **Issue / parent epic:** #
- **Commit SHA:** abcdef1
- **Branch:** feature/example
- **Risk tier:** Low / Medium / High

### Changed Areas
<!-- Which modules/files were modified -->
- :module:area — _what changed_

### Evidence Summary

| Category | Status | Details |
|----------|--------|---------|
| Automated tests | ✅ / ⚠️ / ❌ | Commands run: `./gradlew ...` |
| CI run | ✅ / ⚠️ / ❌ | Run # or URL: |
| S21 device | ✅ / ⚠️ / ❌ / N/A | Model / Android version: |
| S23U device | ✅ / ⚠️ / ❌ / N/A | Model / Android version: |
| Screenshots | ✅ / ⚠️ / ❌ / N/A | Path(s): |
| Pre-flight oracle | ✅ / ⚠️ / ❌ / N/A | Status: |
| Manual on-device checks | ✅ / ⚠️ / ❌ / N/A | Checks completed: |
| Review only | ✅ / N/A | |

### Evidence Files
<!-- Paths to evidence JSON, screenshots, logs -->
- `docs/test-triage/evidence/...`
- `screenshots/...`

### Device Details
<!-- When device testing was performed -->
- **S21:** One UI version / Android version / Connection (USB/TCP)
- **S23U:** One UI version / Android version / Connection (USB/TCP)

### Manual Checks Completed
<!-- Only if manual on-device testing was done -->
- [ ] STT/TTS audio path
- [ ] Wake word / VAD behaviour
- [ ] Audio focus (acquire + release)
- [ ] Permission flows (first-run, denied, revoked, repair)
- [ ] Rotation (portrait ↔ landscape)
- [ ] Theme switching (light ↔ dark)
- [ ] Font scale — content not clipped
- [ ] TalkBack focus order
- [ ] Back-stack / navigation behaviour
- [ ] Touch targets ≥ 48×48dp

### Evidence Waivers
<!-- Any evidence intentionally skipped, with rationale -->
| Waived Item | Rationale |
|-------------|-----------|
| | |

### Known Limitations
<!-- What this evidence does not cover -->
- 

### Deferred Follow-ups
<!-- Issues created for deferred work -->
- # —
```

## Field Guidance

### Status Legend
| Status | Meaning |
|--------|---------|
| ✅ | Completed and passing |
| ⚠️ | Completed with issues or partial |
| ❌ | Failed or blocked |
| N/A | Not applicable at this risk tier |

### Evidence Categories Explained

- **Automated tests:** Unit and instrumentation tests run locally or in CI.
- **CI run:** Link to the GitHub Actions run that validates this PR.
- **S21 / S23U device:** Physical device test evidence from ADB harness or manual testing.
- **Screenshots:** Before/after visual evidence for UI changes.
- **Pre-flight oracle:** Harness health check (test harness changes only).
- **Manual on-device checks:** Human-verified behaviour (audio, permissions, UI alignment).
- **Review only:** Change verified by code review alone (docs, config, build).

### Distinguishing Evidence Types

- **Automated evidence:** Generated by CI or local `./gradlew` commands.
- **Manual on-device testing:** Physical device run with human observation.
- **Manual review only:** Code review confidence without device testing.
- **Waived evidence with rationale:** Intentionally skipped, documented with justification.

## Example (Medium Risk S21-only PR)

```markdown
## Evidence Manifest

### PR Metadata
- **PR number:** #1234
- **Issue / parent epic:** #1219
- **Commit SHA:** a1b2c3d
- **Branch:** feature/example
- **Risk tier:** Medium

### Changed Areas
- `:feature:settings` — Added model info selection screen

### Evidence Summary

| Category | Status | Details |
|----------|--------|---------|
| Automated tests | ✅ | `./gradlew :feature:settings:testDebugUnitTest` passes |
| CI run | ✅ | Run #987654 |
| S21 device | ✅ | S21 Exynos, One UI 6.1, Android 15, USB |
| S23U device | N/A | No device-sensitive changes |
| Screenshots | ✅ | `screenshots/pr-1234-model-info-before.png`, `screenshots/pr-1234-model-info-after.png` |
| Manual on-device checks | N/A | No voice, audio, or permission changes |

### Evidence Files
- `results/pr/1234/evidence.json`

### Device Details
- **S21:** One UI 6.1 / Android 15 / USB connection

### Evidence Waivers
| Waived Item | Rationale |
|-------------|-----------|
| S23U evidence | No device-sensitive or inference changes |
| Manual on-device checks | Settings-only change with no audio/permission impact |

### Known Limitations
- Tested on S21 only; S23U visual differences possible but unlikely

### Deferred Follow-ups
- (none)
```
