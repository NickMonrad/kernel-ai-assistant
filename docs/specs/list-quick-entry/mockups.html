Rules

  • Item name: one line. Enter adds the item and starts the next.
  • Description: several lines. Enter adds a new line.
  • Before a batch: Cancel and Add. During a batch: Done and Add & next.
  • Done, or swiping the sheet down, also adds any text left in the Item box.
  • Star, due date and description reset after each item.
  • The hint stops showing after you've used it three times, or dismissed it. The counter stays.
  • Sub-items work the same way, under the same parent.
