# Brand assets

- `jandal-icon.svg`: master app icon, copied from `app/src/main/res/drawable/ic_launcher_background.xml` and `ic_launcher_foreground.xml`. Keep in sync if the launcher icon changes.
- `jandal-icon-512.png`: 512×512 32-bit PNG rendered from the SVG, for the Play hi-res icon.
- `jandal-mark.svg`: line mark on a transparent background, from `ic_launcher_monochrome.xml`.
- `jandal-feature-graphic-1024x500.png`: Google Play feature graphic.
